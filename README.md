# AI Playground, minor Circulaire Economie

Studentenpagina's voor het playground-deel op de donderdagmiddag, HAN minor Circulaire Economie, studiejaar 2026-2027.

Live: https://guuswitjes.github.io/minor-ce-playground/

De opzet volgt de studentenhandleiding van de minor: losse HTML-pagina's, geen build-stap, dezelfde stylesheet zodat het voor studenten één geheel is.

| Pagina | Waarvoor |
|---|---|
| `index.html` | Overzicht van de playground en de zeven sessies |
| `sessie-1.html` | De opdrachten van sessie 1, 10 september |
| `uitkomst-1` tot en met `uitkomst-4` | Materiaal voor de blinde vergelijking |
| `onthulling.html` | De prompts achter die vier uitkomsten. Staat niet in het menu |

Stylesheet en menuscript komen uit de publieke studentenhandleiding-repo van de minor, zodat beide sites er hetzelfde uitzien.

Docent: Guus Witjes.
